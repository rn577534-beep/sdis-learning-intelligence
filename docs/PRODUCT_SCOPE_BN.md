# SDIS MVP v0.1 — পণ্যের সীমা ও কাজের তালিকা

## লক্ষ্য
একটি সীমিত শিক্ষণ-চক্র কাজ করানো: মূল্যায়ন → দক্ষতা-ভিত্তিক প্রমাণ → অনুশীলনের সুপারিশ → পুনর্মূল্যায়ন → প্রতিবেদন।

## এই সংস্করণে বাস্তবায়িত
- শিক্ষার্থীর ন্যূনতম প্রোফাইল
- ডেমো শিখনফল ও ডেমো মূল্যায়ন
- উত্তর জমা ও সরল স্কোরিং
- শিখনফলভিত্তিক ফলাফল
- প্রাথমিক অনুশীলন পরিকল্পনা
- অগ্রগতির প্রতিবেদন
- API ডকুমেন্টেশন ও মৌলিক টেস্ট

## এখনো বাস্তবায়িত নয়
- লগইন/পরিচয় যাচাই এবং ভূমিকা-ভিত্তিক অনুমতি
- অভিভাবক/শিক্ষকের সম্মতি সংগ্রহ
- প্রকৃত NCTB কারিকুলাম যাচাই ও ম্যাপিং
- শিক্ষক ড্যাশবোর্ড ও শিক্ষার্থী মোবাইল অ্যাপ
- LLM/AI API সংযোগ
- বহু প্রতিষ্ঠানের পৃথক ডেটা-সীমা
- উন্নত নিরাপত্তা পরীক্ষা, ব্যাকআপ, ডেটা মুছে ফেলার কর্মপ্রবাহ
- বৈজ্ঞানিকভাবে যাচাইকৃত mastery model

## গ্রহণযোগ্যতার প্রাথমিক মানদণ্ড
1. শিক্ষার্থী তৈরি করা যায়।
2. মূল্যায়নের উত্তর জমা দিলে ফলাফল সংরক্ষিত হয়।
3. প্রতি শিখনফলের ফল আলাদাভাবে দেখা যায়।
4. শেখার পরিকল্পনায় সুপারিশের কারণ লেখা থাকে।
5. অগ্রগতি প্রতিবেদন পূর্ববর্তী প্রচেষ্টা দেখায়।
6. ডেমো ডেটা স্পষ্টভাবে ডেমো হিসেবে চিহ্নিত।
7. AI বা স্কোর কোনো শিক্ষার্থীকে স্থায়ীভাবে “দুর্বল” বা “অযোগ্য” বলে চিহ্নিত করে না।

## পরবর্তী নির্মাণ ধাপ
1. বাংলাদেশের নির্দিষ্ট শ্রেণি ও বিষয় নির্বাচন করে বর্তমান NCTB শিখনফল যাচাই।
2. অনুমতি, সম্মতি ও নিরাপত্তার স্তর তৈরি।
3. মূল্যায়নের রুব্রিক ও শিক্ষক যাচাই যোগ।
4. পরীক্ষাযোগ্য AI gateway ও structured output।
5. ছোট, তত্ত্বাবধানে পরিচালিত পাইলট; শেখার উন্নতি ও পক্ষপাত মাপা।
